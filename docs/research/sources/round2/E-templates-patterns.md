# E · Templates, patterns, examples
Retrieved: 2026-09-24

## Summary
Carbon's org spreads "prebuilt page material" across three layers: (1) code starters/examples that show app shells, routing, theming, and a few real pages (dashboard, welcome, data-table patterns); (2) design-only Patterns documentation on carbondesignsystem.com, which is guidance text with almost no shipped code; (3) IBM Products (React components for page-level furniture: PageHeader, Tearsheet, EmptyState variants, ErrorEmptyState, NotificationsPanel) and Carbon for IBM.com (marketing-site blocks/sections; its `@carbon/ibmdotcom-react` package's source was removed from `main` per round-1's research, and the current `web-components` package's own peer dependencies still pin `react`/`react-dom` to `^16.10.0 || ^17.0.0` with no `components-react` wrapper directory found in the tree; net effect for a React-19 target is no current maintained React layer). The single most valuable code source for "sections/blocks" is `carbon-react-router-starter` (current, React 19, has a real dashboard page, welcome page with reusable sections, common header/nav/footer, i18n, theming). The single most valuable source for "data table blocks" is `tanstack-carbon` (active Sept 2026, ~20 named React data-table patterns), surfaced via the `generate-pattern` CLI. Most `carbon/examples/*` are narrow single-topic demos (prefixing, theming, token compat), not page templates. Older tutorial/template repos (`carbon-nextjs-template`, `carbon-tutorial-nextjs`) are stale (2023-2024, Next 12-13, React 17-18) and not real page libraries.

## Page-level templates found
- Dashboard page: `carbon-react-router-starter` `src/pages/dashboard/` (Dashboard.jsx, DashboardNumberTiles.jsx, DashboardURLParameters.jsx, DashboardVisualizations.jsx) plus the Data visualization "dashboards" guidance page. `core`.
- Welcome/landing page with composable sections: `carbon-react-router-starter` `src/pages/welcome/` (Header, AboutSection, Callout, CommandSnippet, FeatureTile, FeaturesSection, FetchingSection, HighlightTile, RunSection, PostComponent). `core`.
- Not-found / error page: `carbon-react-router-starter` `src/pages/not-found/NotFound.jsx`; IBM Products `FullPageError`, `NotFoundEmptyState`, `UnauthorizedEmptyState`. `core`.
- Login page: design guidance only at `/patterns/login-pattern/`; no shipped Carbon React login page template found in the starters. `core` as a target to build, `optional` source material.
- Settings/wizard/create-edit flow pages: IBM Products `CreateFullPage(Step)`, `EditFullPage`, `CreateTearsheet(Step/Divider)`, `EditTearsheet(Form/Narrow)`. `core`.
- Table/list page: `tanstack-carbon` react examples (pagination, sorting, filtering, row actions, sticky columns, infinite scroll, nested rows) function as a de-facto "table page" toolkit; IBM Products `Datagrid`/`useDatagrid` wraps similar concerns as a component. `core`.
- Admin/app-shell page: `carbon-react-router-starter`'s CommonHeader + Nav (header/side items) + Footer + ProfilePanel + page-layout.jsx is the closest thing to a full admin shell template in the org. `core`.
- Empty-state pages/sections: IBM Products EmptyState family (see above) directly implements the `/patterns/empty-states-pattern/` guidance. `core`.
- Marketing/landing page sections (hero, CTA, pricing, feature, card sections): only found as web-components in `carbon-for-ibm-dotcom`; would need a React rebuild. `reference`.
