# D · Carbon Labs, extensions and tooling
Retrieved: 2026-09-24

## Summary
Carbon Labs (github.com/carbon-design-system/carbon-labs) is an incubation monorepo of 38 published `@carbon-labs/*` npm packages (React and Web Component pairs plus shared utilities/primitives), all Apache-2.0, actively published through September 2026. No documented graduation policy into `@carbon/react` or `@carbon/ibm-products` was found; `react-resizer` is already consumed by IBM Products, which is the only observed graduation-like signal. Outside Labs, the org has one actively maintained, React-usable, non-Carbon-core extension worth close attention: `@carbon/charts` + `@carbon/charts-react` (dataviz, 1049 stars, published 2026-09-16) with matching theme packages for ECharts and Vega. `carbon-ai-chat` (`@carbon/ai-chat`) is a separately maintained, actively developed chat framework (React + Web Components), published 2026-09-21, distinct from the older `@carbon-labs/ai-chat` in the Labs monorepo. `tanstack-carbon` is an exploratory repo (not an installable package) documenting IBM Products' investigation of TanStack Table as a Datagrid replacement — directly relevant to any React data-table decision. `carbon-addons-iot-react`, `carbon-addons-cloud`, `carbon-addons-data-viz-react`, `ibm-security` and `carbon-addons-cloud-react/vanilla` are all deprecated or superseded (mostly pointing at Carbon v11, `@carbon/charts`, or the ibm-cloud-cognitive monorepo) and are `out`. Dev tooling worth adopting directly: `stylelint-plugin-carbon-tokens` (independently maintained, v5, Carbon v11-only, MIT, actively published 2026-06-03), `@carbon/upgrade` (official codemod tool, actively published 2026-09-23), and `devtools` (Carbon's own browser extension + component-list/utilities packages, Apache-2.0, last push 2026-06-17). `carbon-mcp` is issue-tracking only in the public repo; the actual MCP server/tools are described on carbondesignsystem.com and were previously found to be access-gated to IBM (round 1, unverified confirmed).

## Open questions
- No documented Carbon Labs graduation policy was found publicly; the internal contributing guide linked from the Labs README (pages.github.ibm.com/carbon/ibm-products/contributing/carbon-labs) is inaccessible from outside IBM. (unverified)
- `carbon-mcp` public repo is issue-tracking only; whether the actual MCP server requires IBM-internal auth could not be re-confirmed beyond the round-1 finding (unverified).
- License for `tanstack-carbon`, `carbon-addons-cloud`, `carbon-vega-theme`, and the `devtools` sub-packages (`component-list`, `utilities`) not individually confirmed beyond the repo-level license field (unverified where marked "not confirmed").
- Whether any `@carbon-labs/*` package has ever actually "graduated" out of Labs into `@carbon/react` proper (as opposed to being consumed as a dependency by `@carbon/ibm-products`) is unconfirmed (unverified).
- Exact npm package name/existence for `carbon-vega-theme` was not found in 00-inventory.json or via direct registry lookup within budget; treated as a theme asset rather than a versioned package (unverified).
