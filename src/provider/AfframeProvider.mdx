# AfframeProvider

<SourceLabel name="afframe" />

[Source code](https://github.com/afframe/ui/tree/main/src/provider)

Wrap the app once, near the root. The provider turns on the Carbon feature
flags Afframe UI uses in React; the stylesheet carries their Sass side
([Feature Flags](?path=/docs/getting-started-feature-flags--overview)). It also
renders Carbon's `GlobalTheme` with the theme on `<html>`, so Carbon's
`useTheme()` reports `white` or `g100`. A `GlobalTheme` of the app above the
provider is replaced; one inside it wins for its subtree and can disagree with
the page's CSS theme, so leave it out.

Without the provider, Carbon, IBM Products and Afframe modals render inline in
the page with no backdrop: the stylesheet expects the native `dialog` element
that only the provider's flag turns on.

```tsx
import '@afframe/ui/styles.css';
import { AfframeProvider } from '@afframe/ui';

<AfframeProvider>{children}</AfframeProvider>;
```
