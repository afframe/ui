## Accessibility

A skeleton has no role and no text, so a screen reader does not announce it.
Put `aria-busy="true"` on the region that is loading and set it back to
`false` when the content arrives:

```jsx
<section aria-busy={loading} aria-label="Invoices">
  {loading ? <SkeletonText paragraph lineCount={3} /> : <InvoiceList />}
</section>
```
