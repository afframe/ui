## Typing a time

Afframe's `FluidTimePicker` wraps Carbon's and takes the same time props as
[TimePicker](?path=/docs/components-timepicker--overview): 24-hour
`hh:mm` masked to `defaultTimeFormat` in `@afframe/ui/format`, `seconds` for
`hh:mm:ss`, `hourCycle="h12"` for a field with an AM/PM select, and
`inputMask={false}` for Carbon's input. Keep at least one select: with the
input alone, Carbon sizes it to half the field.

## Accessibility Considerations

### Error message and screen readers

In Carbon 1.118, an invalid or warned FluidTimePicker renders its message
without an id and sets no `aria-invalid`, so screen readers announce neither
the state nor the reason. Until Carbon fixes it, wrap the message in an element
with an id and link it while the state is set; Carbon passes both attributes on
to the input:

```tsx
<FluidTimePicker
  id="start-time"
  labelText="Start time"
  invalid={invalid}
  invalidText={<span id="start-time-error">Enter a time as hh:mm.</span>}
  {...(invalid && {
    'aria-invalid': true,
    'aria-describedby': 'start-time-error',
  })}>
  {/* selects */}
</FluidTimePicker>
```

For a warning, link `warnText` the same way without `aria-invalid`.

### Accessible Name

To comply with accessibility requirements, make sure to supply the component
with an accessible name by providing either the `aria-label`, `aria-labelledby`
or `title` attribute. Read more on the accessible naming rule
[here](https://able.ibm.com/rules/archives/latest/doc/en-US/aria_accessiblename_exists.html).
