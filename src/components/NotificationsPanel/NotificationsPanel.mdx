<SourceLabel name="ibm-products" />

## Overview

`NotificationsPanel` opens from a bell in the UI shell header and lists the
user's notifications by day, with read more, dismiss, do not disturb and a
link to all notifications. With no notifications it shows its own empty state.

Use it for notifications that collect over time. For a message about the page
the user is on, use a Carbon notification from the
[Notifications](?path=/docs/components-notifications-inlinenotification--overview)
family. Use
[NotificationsEmptyState](?path=/docs/components-empty-states-notificationsemptystate--overview)
for an empty notifications view outside this panel.
