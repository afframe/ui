## Accessibility Considerations

### Accessible Name

FluidForm renders a `<form>`. Name it with `aria-label`, or `aria-labelledby`
pointing at the heading above it, so screen readers list it as a form
landmark. Each field inside takes its name from its own label prop
(`labelText`, `titleText` or `label`; see the field props table above).

### Error messages

The fields keep their own error wiring inside FluidForm. FluidTextInput and
FluidPasswordInput need `aria-describedby="<id>-error-msg"` while `invalid` is
set, as the Default story does; see the
[FluidTextInput page](?path=/docs/components-fluid-inputs-fluidtextinput--overview).
