# Feature flags

<SourceLabel name="afframe" />

Afframe UI runs Carbon v11 with the v12 feature flags off except the focus
wrap flag, and a few opt-in flags on; the menu wrappers turn
`enable-v12-overflowmenu` on per instance. Consumers set nothing:
`AfframeProvider` turns the flags on in React and `styles.css` is built with
their Sass side; the two lists differ where Carbon reads a flag on one side
only (`docs/feature-flags.md`).

## React flags

`AfframeProvider` wraps the app in Carbon's `FeatureFlags` with:

- `enableDialogElement`
- `enableFocusWrapWithoutSentinels` (React only)
- `enablePresence`
- `enableEnhancedFileUploader`
- `enableTreeviewControllable`

## Sass flags

`styles.css` is compiled with:

- `enable-dialog-element`
- `enable-presence`
- `enable-enhanced-file-uploader`
- `enable-treeview-controllable`
- `enable-tile-contrast` (Sass only: Carbon React never reads it)
