# Feature flags

<SourceLabel name="afframe" />

Afframe UI runs Carbon v11 with the v12 feature flags on. Consumers set
nothing: `AfframeProvider` turns the flags on in React and `styles.css` is built
with the same flags in Sass.

## React flags

`AfframeProvider` wraps the app in Carbon's `FeatureFlags` with:

- `enableV12Release`
- `enableDialogElement`
- `enablePresence`
- `enableEnhancedFileUploader`
- `enableTreeviewControllable`

## Sass flags

`styles.css` is compiled with:

- `enable-v12-release`
- `enable-dialog-element`
- `enable-presence`
- `enable-enhanced-file-uploader`
- `enable-treeview-controllable`
- `enable-tile-contrast`
