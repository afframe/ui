# Structured List

<SourceLabel name="carbon" />

[Source code](https://github.com/carbon-design-system/carbon/tree/v11.117.0/packages/react/src/components/StructuredList)

In Afframe UI, `enable-v12-release` turns on
`enable-v12-structured-list-visible-icons` in `AfframeProvider` and in
`styles.css`, so the stories next to this page render with the flag on.

## The feature flag `enable-v12-structured-list-visible-icons` will enable structured list visible icons

```js
<FeatureFlags enableV12StructuredListVisibleIcons>
  <StructuredList />
</FeatureFlags>
```
