# ActionBar

<SourceLabel name="ibm-products" />

[Source code](https://github.com/carbon-design-system/ibm-products/tree/%40carbon%2Fibm-products%402.100.0/packages/ibm-products/src/components/ActionBar)

`ActionBar` renders a row of icon-only ghost buttons. Each item in `actions` needs
a `key`, a `renderIcon`, an `iconDescription` and a `label`, plus an optional
`onClick`; other fields go to the Carbon `Button`. Items that do not fit the
container width, or go past `maxVisible`, move into an overflow menu.

Pass `renderIcon` as a function, `(props) => <Bee size={16} {...props} />`, not
the icon component itself: the overflow menu renders anything that is not a
function as a React child, and a Carbon icon component is an object, so the menu
throws once an item overflows.

<Canvas of={stories.Default} />

Pick "A lot" in the `actions` control, or narrow `containerWidth`, to see the
overflow menu.

## Keyboard and screen readers

Each item is a Carbon `IconButton`: Tab moves between the items, Enter and Space
activate the focused one, and its `label` is the accessible name and the tooltip
shown on focus and hover.

The overflow menu is a Carbon `OverflowMenu` with `OverflowMenuItem` children:
`overflowAriaLabel` names its trigger, Enter or Space opens it, and the arrow
keys move between the items.
