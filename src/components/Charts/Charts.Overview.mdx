# Charts

<SourceLabel name="extras" />

Two chart libraries ship with `@afframe/ui`. Carbon Charts are the
`@carbon/charts-react` wrappers, with the page theme as their default and their
styles in `@afframe/ui/charts.css`. Use them for dashboards and reports: they
follow Carbon's data visualization guidelines and come with a legend, tooltips,
a toolbar and a "Show as table" view.

`EChart` wraps one Apache ECharts instance with the Carbon theme. Use it for a
chart type or an interaction Carbon Charts does not have, or for large data
sets: it draws on a canvas instead of SVG, so it has no "Show as table" view.
