# Toolbar

<SourceLabel name="ibm-products" />

[Source code](https://github.com/carbon-design-system/ibm-products/tree/%40carbon%2Fibm-products%402.101.0/packages/ibm-products/src/components/Toolbar)

`Toolbar` is a `role="toolbar"` container of `ToolbarGroup`s, each holding
controls such as `ToolbarButton`, Carbon form controls and menus. Set
`vertical` to stack the groups in a column.

## Keyboard and screen readers

Every control is a Tab stop until one gets focus; from then on the toolbar is
one Tab stop that returns to the last focused control. ArrowRight and ArrowLeft
move focus to the next and previous control, across groups, or ArrowDown and
ArrowUp when `vertical` is set. Focus stops at the first and last control; Home
and End do nothing. Each `ToolbarButton` is a Carbon `IconButton`, so its
`label` is the accessible name and the tooltip shown on focus and hover.
