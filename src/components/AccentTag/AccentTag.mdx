# AccentTag

<SourceLabel name="afframe" />

[Source code](https://github.com/afframe/ui/tree/main/src/components/AccentTag). See also [Tag](https://carbondesignsystem.com/components/tag/usage/).

`AccentTag` is a clickable tag with a tooltip and a coloured strip on its
inline-start edge. It is built on Carbon's `OperationalTag` (a gray tag) and
`Tooltip`. It is a client module.

AccentTag is an Afframe addition: Carbon has no tag with an accent strip.
Use Carbon's `Tag` with a `type` colour when the whole tag should carry the
colour, for example a status. Use AccentTag when the tag stays neutral, the
colour marks a category beside it, and the tag needs a tooltip or an action.

## Usage and props

```tsx
'use client';
import { AccentTag } from '@afframe/ui';

<AccentTag
  text="Acme Trading"
  accent="red"
  tooltip="Two invoices overdue"
  accentLabel="Overdue"
  onClick={() => openCustomer('acme')}
/>;
```

- `accent` is one of Carbon's tag colours. The strip is 4 px
  (`$spacing-02`) wide and uses that colour's tag border token
  (`$tag-border-<name>`), so it follows the light and dark themes. A disabled
  tag shows the strip in `$border-disabled`. The three grays differ only
  slightly. The strip follows the rounded start of the pill-shaped tag, so it is
  curved.
- The strip is decorative. If the colour means something, say it in text:
  `accentLabel` adds that text to the tag's accessible name. With
  `announceAccent`, the name gets `messages.accentLabel(accent)` ("Red
  accent") instead.
- `size` is `md` (24 px, default) or `lg` (32 px). Carbon's `sm` tag is
  about 20 px high, under the 24 px target size, so it is not offered.
- Without `onClick` the tag is still a button, so keyboard users can reach
  the tooltip.
- `tooltip` must not hold links or buttons; Carbon's tooltip is not
  interactive.
- `className`, `ref`, `id` and other attributes go to the tag button, as on
  Carbon's `IconButton`. `type` and `aria-describedby` are not passed: the
  first is the tag colour in Carbon, the second would replace the tooltip.

## Messages

| Key           | Default                  | Used for                                   |
| ------------- | ------------------------ | ------------------------------------------ |
| `accentLabel` | "Red accent", per colour | `(color) => string`, with `announceAccent` |

`accentLabel` is a function: pass `messages` from a client component.

## Keyboard and screen reader behaviour

- The tag is a `button` named by its text, plus the accent text when
  `accentLabel` or `announceAccent` is set. It is described by the tooltip
  (`aria-describedby`).
- Tab focuses the tag and opens the tooltip. Hover opens it too, and it stays
  open while the pointer is over it. Escape closes it; focus stays on the tag.
- Enter and Space call `onClick`.
- A disabled tag is skipped by Tab and does not call `onClick`.
