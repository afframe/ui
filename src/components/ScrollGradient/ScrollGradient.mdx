## Overview

The ScrollGradient implements gradient fades in horizontal and vertical
directions based on the user's scroll position. Visually, it informs the user of
more content that can be scrolled to.

In Afframe UI, `ScrollGradient` is an IBM Products canary component whose
setting Afframe turns on when the export loads, so no `pkg` call is needed. The
fade defaults to `var(--cds-layer-01)`: pass `color` with the surface the
component sits on, such as `var(--cds-background)`, or the fade shows as a band.
In `@carbon/ibm-products` 2.101.0 the horizontal start fade (left edge) is not
painted; the other three fades are.

## Accessibility

The scroll element is an inner `div` with no tab stop and no name. Use
`getScrollElementRef` to make it reachable by keyboard and to name it, as the
stories do:

```jsx
<ScrollGradient
  color="var(--cds-background)"
  getScrollElementRef={(element) => {
    if (!element) return;
    element.tabIndex = 0;
    element.setAttribute('role', 'region');
    element.setAttribute('aria-label', 'Invoices');
  }}>
  <InvoiceList />
</ScrollGradient>
```
