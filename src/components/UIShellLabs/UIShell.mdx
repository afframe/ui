## Overview

The Labs UI Shell is composed from Carbon and Carbon Labs components, all
exported by `@afframe/ui`. Where a Labs component shares a Carbon name, Carbon
keeps the name and the Labs one ends in `Labs`. Additional documentation and
examples for the Carbon components can be found in the
[Carbon React Storybook](https://react.carbondesignsystem.com/?path=/docs/components-ui-shell-header--overview).
The following components come from Carbon Labs:

- `HeaderContainerLabs`
- `HeaderDivider`
- `HeaderOverflowPanel`
- `HeaderPopover`
- `HeaderPopoverActions`
- `HeaderPopoverButton`
- `HeaderPopoverContent`
- `Profile`
- `SideNavLabs`
- `SideNavItemsLabs`
- `SideNavLinkLabs`
- `SideNavMenuLabs`
- `SideNavMenuItemLabs`
- `SideNavSlot`
- `SideNavTitle`
- `TrialCountdown`

## Getting started

Install `@afframe/ui`:

```bash
pnpm add @afframe/ui
```

The Labs UI Shell styles ship in the package CSS, `@afframe/ui/styles.css`.

### JS (imports)

Import the components and any icons needed from `@afframe/ui` to build your UI
Shell.

```javascript
import {
  SideNavLabs,
  SideNavItemsLabs,
  SideNavMenuLabs,
  SideNavMenuItemLabs,
  SideNavLinkLabs,
  HeaderPopover,
  HeaderPopoverActions,
  HeaderPopoverButton,
  HeaderPopoverContent,
  HeaderContainerLabs,
  HeaderDivider,
  HeaderOverflowPanel,
  Profile,
  SkipToContent,
  Header,
  HeaderName,
  Theme,
  HeaderMenuButton,
  SideNavDivider,
  Content,
  Grid,
  Column,
  HeaderGlobalBar,
  HeaderGlobalAction,
  HeaderNavigation,
  HeaderMenuItem,
  HeaderMenu,
  Switcher,
  SwitcherItem,
  SwitcherDivider,
  MenuButton,
  MenuItemRadioGroup,
  ExpandableSearch,
  Link,
  Button,
} from '@afframe/ui';
import { Help, Settings, UserAvatar } from '@afframe/ui/icons';
```
