## Overview

The overflow menu component is a clickable element that contains additional
options that are available to the user, but there is a space constraint.

<Canvas of={OverflowMenuStories.Default} />

### `data-floating-menu-container`

`OverflowMenu` uses React Portals to render the overflow menu into the DOM. To
determine where in the DOM the menu will be placed, it looks for a parent
element with the `data-floating-menu-container` attribute. If no parent with
this attribute is found, the menu will be placed on `document.body`.

## Customizing the tooltip

The `OverflowMenu` uses an `IconButton` under the hood, which means it can
accept any props that an `IconButton` can receive and will successfully pass
those forward. To modify the tooltip's alignment, you may make use of the
`align` property as described in the `IconButton` props:

```jsx
<OverflowMenu aria-label="overflow-menu" align="bottom">
  <OverflowMenuItem itemText="Stop app" />
  <OverflowMenuItem itemText="Restart app" />
  <OverflowMenuItem itemText="Rename app" />
  <OverflowMenuItem itemText="Clone and move app" disabled requireTitle />
  <OverflowMenuItem itemText="Edit routes and access" requireTitle />
  <OverflowMenuItem hasDivider isDelete itemText="Delete app" />
</OverflowMenu>
```

## Menu items from 1.0.1

Give the trigger its name with `iconDescription` and the menu its name with
`aria-label`; the children are `OverflowMenuItem` with `itemText`. Code written
for `@afframe/ui` 1.0.x still works: a `label` prop, or `MenuItem` children
(also `MenuItemDivider`, `MenuItemGroup`, `MenuItemRadioGroup`,
`MenuItemSelectable`) placed directly or in one Fragment, switch that one menu
to Carbon's newer menu. It renders Carbon's `Menu` with its v11 look and works
by keyboard; `label` names the trigger and the menu, and `menuAlignment` sets
where it opens (the v11 menu ignores it). MenuItems inside your own wrapper
component, or passed from a React Server Component, are not detected, so pass
`label` there.

<Canvas of={OverflowMenuStories.MenuItemsFrom101} />

```jsx
import { MenuItem, MenuItemDivider, OverflowMenu } from '@afframe/ui';

<OverflowMenu label="Row actions" menuAlignment="bottom-start">
  <MenuItem label="Edit" onClick={handleEdit} />
  <MenuItem label="Duplicate" onClick={handleDuplicate} />
  <MenuItemDivider />
  <MenuItem label="Delete" kind="danger" onClick={handleDelete} />
</OverflowMenu>;
```
