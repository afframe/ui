## Overview

Empty states are moments in an app where there is no data to display to the
user. They are most commonly seen the first time a user interacts with a product
or page, but can be used when data has been deleted or is unavailable.

## Afframe notes

### Illustration theme

`EmptyState` shows the `illustration` it is given. For a picture with a light
and a dark version, pick the source from the page's colour scheme in a
`'use client'` component
([Theming](?path=/docs/getting-started-theming--overview)):

```tsx
'use client';
import { EmptyState, useColorScheme } from '@afframe/ui';
import customersLight from './customers-light.svg';
import customersDark from './customers-dark.svg';

export function NoCustomers() {
  const scheme = useColorScheme();
  return (
    <EmptyState
      illustration={scheme === 'dark' ? customersDark : customersLight}
      illustrationDescription=""
      title="No customers yet"
      subtitle="Add a customer to send them invoices."
    />
  );
}
```

`useColorScheme()` returns `light` on the server render and the first client
render, so a dark page shows the light picture until the client renders again.

### Illustration alt text

IBM renders the `illustration` image with `aria-hidden="true"`, so screen
readers skip it whatever `illustrationDescription` says; the title and
subtitle carry the meaning. `illustrationDescription` is still the image's
`alt`, shown when the picture fails to load. With Custom Illustration passes
`""` because the title sits next to the picture.
