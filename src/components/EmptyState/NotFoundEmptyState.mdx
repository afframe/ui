## Afframe notes

### Illustration theme

IBM draws the light illustration unless the app passes `illustrationTheme`.
Pass the page's colour scheme from a `'use client'` component
([Theming](?path=/docs/getting-started-theming--overview)):

```tsx
'use client';
import { NotFoundEmptyState, useColorScheme } from '@afframe/ui';

export function NoMatchingInvoices() {
  return (
    <NotFoundEmptyState
      illustrationTheme={useColorScheme()}
      title="No invoices match your search"
      subtitle="Try another invoice number or customer name."
    />
  );
}
```

`useColorScheme()` returns `light` on the server render and the first client
render, so a dark page shows the light illustration until the client renders
again. The stories on this page follow the Storybook theme the same way; With
Dark Mode Illustration sets `illustrationTheme="dark"` explicitly.

### Illustration alt text

The illustration is hidden from screen readers (`aria-hidden="true"`).
`illustrationDescription`, or the title when it is empty, only fills the SVG's
`<title>`, which shows as a tooltip. The title and subtitle carry the meaning.
