## When to use

Use get started cards on a get started page, one card per first task, in
sequence where order matters. Do not use them for:

- progress through setup tasks in a panel: [Checklist](?path=/docs/components-onboarding-checklist--overview);
- general clickable content: Carbon [Tile](?path=/docs/components-tile--overview).
