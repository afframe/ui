# Reduced toggle label spacing

<SourceLabel name="carbon" />

[Source code](https://github.com/carbon-design-system/carbon/tree/v11.117.0/packages/react/src/components/Toggle)

In Afframe UI, `enable-v12-release` turns on
`enable-v12-toggle-reduced-label-spacing` in `styles.css`, so the stories next
to this page render with the flag on.

Reduced spacing between the toggle control and its label to improve visual
consistency with other form inputs.
