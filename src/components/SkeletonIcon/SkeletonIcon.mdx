## Accessibility

A skeleton has no role and no text, so a screen reader does not announce it.
Put `aria-busy="true"` on the region that is loading and set it back to
`false` when the content arrives:

```jsx
<section aria-busy={loading} aria-label="Invoices">
  {loading ? <SkeletonText paragraph lineCount={3} /> : <InvoiceList />}
</section>
```

## IconSkeleton

`IconSkeleton` is Carbon's `Icon.Skeleton` under its export name. It renders the
same element as `SkeletonIcon`: a `div` with the `cds--icon--skeleton` class.
Only the types differ: `IconSkeletonProps` takes every `div` prop, while
`SkeletonIconProps` takes only `className` and passes other props through at
runtime without types. Prefer `SkeletonIcon` and size it with a class; use
`IconSkeleton` when the code needs typed `style` or other `div` props.
