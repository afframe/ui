## 24-hour time

Carbon's default `pattern` accepts 12-hour times only. For 24-hour time, as in
Czech forms, render the input without the AM/PM select and pass the pattern:

```tsx
<TimePicker
  id="start-time"
  labelText="Start time"
  placeholder="hh:mm"
  pattern="(?:[01]\d|2[0-3]):[0-5]\d"
/>
```

The pattern only sets the input's native validity; show the error with
`invalid` and `invalidText`.
