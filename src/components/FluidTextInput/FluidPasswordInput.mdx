## Accessibility Considerations

### Accessible Name

`labelText` renders a visible label tied to the input, which gives the field
its accessible name.

### Error message and screen readers

While `invalid`, Carbon links the error text only through `aria-errormessage`.
Pass `aria-describedby="<id>-error-msg"` while `invalid` is set, as the Invalid
story does; the
[FluidTextInput page](?path=/docs/components-fluid-inputs-fluidtextinput--overview)
has the example.
