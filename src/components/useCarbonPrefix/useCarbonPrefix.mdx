# useCarbonPrefix

<SourceLabel name="carbon" />

[Source code](https://github.com/carbon-design-system/carbon/blob/v11.117.0/packages/react/src/internal/usePrefix.ts)

## Overview

A hook that returns the prefix used in our classes. It is Carbon's `usePrefix`,
exported as `useCarbonPrefix` because `usePrefix` is kept for IBM Products.

## Examples

```js
import { useCarbonPrefix } from '@afframe/ui';

function ExampleComponent() {
  const prefix = useCarbonPrefix();
}
```

Typically, `useCarbonPrefix` will be used to build class names.

```js
import { useCarbonPrefix } from '@afframe/ui';

function ExampleComponent() {
  const prefix = useCarbonPrefix();
  const className = `${prefix}--custom-component`;
}
```
