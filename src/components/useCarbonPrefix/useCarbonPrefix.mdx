# useCarbonPrefix

<SourceLabel name="carbon" />

[Source code](https://github.com/carbon-design-system/carbon/blob/v11.118.0/packages/react/src/internal/usePrefix.ts)

## Overview

A hook that returns the prefix of Carbon's class names. It is Carbon's
`usePrefix`, exported as `useCarbonPrefix` because `usePrefix` is kept for IBM
Products. In Afframe UI the value is always `cds`: `styles.css` is compiled with
that prefix (ADR 0006).

<Canvas of={UseCarbonPrefixStories.Default} />

## Examples

```js
import { useCarbonPrefix } from '@afframe/ui';

function ExampleComponent() {
  const prefix = useCarbonPrefix();
}
```

Typically, `useCarbonPrefix` will be used to build class names.

```js
import { useCarbonPrefix } from '@afframe/ui';

function ExampleComponent() {
  const prefix = useCarbonPrefix();
  const className = `${prefix}--custom-component`;
}
```

`PrefixContext` is the React context behind the hook. Reading it directly gives
the same value; do not provide another prefix, since the stylesheet only has
`cds` classes.
