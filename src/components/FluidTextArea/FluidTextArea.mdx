## Accessibility Considerations

### Accessible Name

`labelText` renders a visible label tied to the text area, which gives the
field its accessible name.

### Error message and screen readers

In Carbon 1.118, FluidTextArea renders its error and warning text with
`role="alert"`, so screen readers announce them. The text area points
`aria-errormessage` at the error; in fluid mode it does not reference the
warning, which is still announced as an alert. Carbon sets `aria-describedby`
after your props, so the FluidTextInput recipe has no effect here and is not
needed.
