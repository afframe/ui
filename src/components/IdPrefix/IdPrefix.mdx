## Overview

The `IdPrefix` component is used to change the prefix applied to the
automatically generated `id` attributes placed on certain DOM elements.

<Canvas of={IdPrefixStories.Default} />

Most apps never need it. Use it when two React roots or micro-frontends render
Carbon components on one page, so their generated ids could collide: give each
root its own prefix. `useIdPrefix` reads the current prefix.

In React, you can use `IdPrefix` anywhere in your component tree and specify the
prefix with the `prefix` prop. Most often it's used in the project root wrapping
the entire project:

```jsx
import { IdPrefix } from '@afframe/ui';

export default function MyApp() {
  return (
    <IdPrefix prefix="custom">
      <Page />
    </IdPrefix>
  );
}
```

`IdPrefix` changes ids only. `styles.css` is compiled with the `cds` class
prefix (ADR 0006), so class prefixes other than `cds` are not supported.
