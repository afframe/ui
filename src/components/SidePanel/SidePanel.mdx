## Feature flags

The SidePanel supports resizable feature through feature flag. The feature can
be enabled by wrapping the component with `FeatureFlags` component and passing
the `enableSidepanelResizer` flag as a prop. the feature can be seen in action
in the stories by enabling the `enableSidepanelResizer` flag in the controls
panel.

<Source
  language="jsx"
  code={`
import { preview__FeatureFlags as FeatureFlags } from '@afframe/ui';
...
<FeatureFlags enableSidepanelResizer>
  <SidePanel
    {...args}
  >
    ...
  </SidePanel>
</FeatureFlags>
`}
/>

## With AI Label

An AI Label is intended for any scenario where something is being generated by
AI to reinforce AI transparency, accountability, and explainability at the UI
level. A Carbon AI Label can be provided to the Tearsheet component by including
an `aiLabel` property on it and providing the carbon AILabel component as its
own custom component.

<Canvas of={SidePanelStories.WithAILabel} />

<Source
  language="jsx"
  code={`
<SidePanel
  {...args}
  aiLabel={
    // carbon AILabel component
    <AILabel
      className="ai-label-container"
      autoAlign={false}
      align="bottom-right"
    >
      <AILabelContent>... ...</AILabelContent>
    </AILabel>
  }
>
  ...
</SidePanel>
`}
/>
