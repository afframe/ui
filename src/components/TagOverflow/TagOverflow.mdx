## Overview

A tag overflow is the use of an interactive tag with the addition of a toggletip
to show additional content.

The need to show additional items related to an object will occur in small
spaces in the UI. A tag overflow count can be used with a group of tags when
there is not enough space to show all tags related to an object. Clicking on the
tag overflow presents a toggletip that lists up to 10 additional tags. If there
are more than 10 additional tags, the toggletip also includes a link to view all
tags. When the user clicks on this link, a modal opens with a list of all the
tags associated with the object.

### Multiline tags

<Canvas of={TagOverflowStories.Multiline}></Canvas>

The `multiline` prop is deprecated and has no effect: TagOverflow only hides
items that do not fit. To wrap tags onto more lines, use `TagSet` with
`multiline`. Passing it also logs a React warning (an upstream bug).

### Considerations

Under the hood this component utilizes the Carbon `Popover` component, which has
an experimental auto-align feature. This feature is disabled by default. If you
are interested in trying this feature please refer to the `autoAlign` prop in
the component API table above as well as the
[Carbon Popover documentation](https://react.carbondesignsystem.com/?path=/docs/components-popover--overview#component-api).
