In Afframe UI, `FluidComboBox` is used as Carbon ships it:

- With `invalid`, the input links `invalidText` through `aria-describedby` but
  gets no `aria-invalid` (an upstream bug), so screen readers do not announce
  the field as invalid. FluidComboBox passes extra props to its input, so pass
  `aria-invalid={invalid}` with `invalid`, as the Invalid story does.

## Accessibility Considerations

### Accessible Name

The accessible name comes from `titleText`: Carbon renders it as the field's
`<label>`, so set it on every field. `placeholder` is only a hint inside the
field and does not name it.
