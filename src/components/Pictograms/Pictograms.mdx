## Overview

Pictograms are Carbon's larger illustrations for marketing and empty states.
Import them from `@afframe/ui/pictograms` with Carbon's names, as in
`@carbon/pictograms-react`. Each pictogram is its own module, so a bundler keeps
only the ones you import.

```jsx
import { Bee } from '@afframe/ui/pictograms';

<Bee width={80} height={80} />;
```

## Size and color

Pictograms are 64 by 64 pixels. Set `width` and `height` to change that; the
`size` prop in the types has no effect on pictograms. They draw with
`currentColor`, so they follow the text color around them.

## Accessibility

A pictogram is decorative by default (`aria-hidden`). When it carries meaning,
give it an `aria-label`; it then gets `role="img"`.
