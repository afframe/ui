# Tile Feature Flags

<SourceLabel name="carbon" />

[Usage guidelines](https://carbondesignsystem.com/components/tile/usage/#feature-flags)

<Meta title="Components/Tile/Feature Flag" name="Flag details" />

[Feature flags](/docs/components-featureflags--overview) have been added
to tile to improve accessibility and change their visual appearance, not their
functionality. Designed to meet accessibility standards, particularly regarding
contrast minimums. This ensures that tiles are more accessible to users with

| Flag                                | Description                                                         | Availability |
| ----------------------------------- | ------------------------------------------------------------------- | ------------ |
| `enable-tile-contrast`              | Enable the improved styling for tiles that provides better contrast | Sass         |
| **Deprecated flags**                |                                                                     |              |
| `enable-experimental-tile-contrast` | Deprecated, use `enable-tile-contrast` instead                      | Sass         |

## Enable tile contrast

The `enable-tile-contrast` flag adds a border to the tile with improved contrast
for accessibility and to visually indicate they are operable.

On in Afframe UI: `styles.css` sets it.
