# First-time orientation pattern

<SourceLabel name="labs" />

[Source code](https://github.com/carbon-design-system/carbon-labs/tree/%40carbon-labs%2Freact-first-time-orientation%400.21.0/packages/react/src/components/FirstTimeOrientation)

## Overview

The first-time orientation pattern is built using the
[InterstitialScreen](?path=/docs/components-onboarding-interstitialscreen--overview)
component
of the Carbon for IBM Products library.

First-time orientation happens from the moment a user gains access to the
product, post login, and guides them to realizing the product's primary value.
The pattern consists of a welcome interstitial and a personalization
interstitial. The personalization interstitial uses
[SelectableTag](https://react.carbondesignsystem.com/?path=/story/components-tag--selectable)
from Carbon.

<Canvas of={Default} />

## When to use

Use the pattern once, on a user's first visit, to welcome them and collect
preferences that tailor the product. Do not use it for:

- announcing new features to returning users: [WhatsNew](?path=/docs/components-onboarding-whatsnew--overview);
- a one-off message in a modal, with or without steps: [InterstitialScreen](?path=/docs/components-onboarding-interstitialscreen--overview);
- pointing at one control on the page: [Coachmark](?path=/docs/components-onboarding-coachmark--overview);
- a list of setup tasks the user works through over time: [Checklist](?path=/docs/components-onboarding-checklist--overview).

## Afframe notes

- **`WelcomeInterstitial` and `PersonalizationInterstitial` are samples.**
  Both take no props: their text, tags and image are fixed in the Labs
  package. Apps write their own steps inside `InterstitialScreen.Body`, and
  use these two only as a reference.
- **The welcome image does not load in an app.** Labs sets the image source
  to a bare file name (`0dbe8337b79d613d.png`) and does not ship the file, so
  the browser requests it next to the current page and gets a 404. This
  Storybook serves its own placeholder under that name; an app that renders
  `WelcomeInterstitial` must serve an image at that path or, better, render
  its own welcome step with its own image.
