In Afframe UI, `FluidMultiSelect` is used as Carbon ships it:

- With `invalid`, the `invalidText` has no id, nothing points to it and the
  field gets no `aria-invalid`, so screen readers do not read the message with
  the field. FluidMultiSelect passes no extra props to the field, so an app
  cannot link it (an upstream bug). Repeat the reason near the form's submit
  button.

## Accessibility Considerations

### Accessible Name

The accessible name comes from `titleText`: Carbon renders it as the field's
`<label>`, so set it on every field. `label` is the placeholder text inside
the field and does not name it.
