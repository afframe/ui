## Overview

The Decorator groups a key/value pair as a single element. This component is not
interactive.

<Canvas of={DecoratorStories.Default} />

## Example **setLabelTitle()**

```jsx

```

setting, which Afframe UI turns on when the component loads
([feature flags](https://github.com/afframe/ui/blob/main/docs/feature-flags.md)).

[AILabel](?path=/docs/components-ai-ailabel--overview); for a status or
