## Overview

The "What's New" pattern is comprised of the Carbon for IBM Product's Tearsheet
component, a few Carbon components and icons, along with the following
components:

**Toc:**

- `Toc`
- `TocList`
- `TocItem`
- `TocSections`
- `TocSection`

**Bubble:**

- `Bubble`
- `BubbleHeader`

**ViewStack:**

- `ViewStack`
- `View`

<Canvas of={WhatsNewStories.WhatsNewPattern} />

## Getting started

Here's a quick example to get you started.

```javascript
import { useRef } from 'react';
import {
  Bubble,
  BubbleHeader,
  Tearsheet,
  Toc,
  TocItem,
  TocList,
  TocSection,
  TocSections,
  View,
  ViewStack,
} from '@afframe/ui';

function App() {
  const tocRef = useRef(null);

  return (
    <>
      {/* Tier 2 - release notification pattern */}
      <Bubble>
        <BubbleHeader>...</BubbleHeader>
        <ViewStack>
          <View>...</View>
        </ViewStack>
        ...
      </Bubble>

      {/* Tier 1 - what's new center pattern */}
      <Toc ref={tocRef}>
        <Tearsheet>
          <Tearsheet.Header>
            <Tearsheet.HeaderContent title="What's new" />
          </Tearsheet.Header>
          <Tearsheet.Influencer>
            <TocList>
              <TocItem>Feature 1</TocItem>
              <TocItem>Feature 2</TocItem>
            </TocList>
          </Tearsheet.Influencer>
          <Tearsheet.Body>
            <Tearsheet.MainContent>
              <TocSections threshold={0.2}>
                <TocSection as="div">...</TocSection>
                ...
              </TocSections>
            </Tearsheet.MainContent>
          </Tearsheet.Body>
        </Tearsheet>
      </Toc>
    </>
  );
}

export default App;
```
