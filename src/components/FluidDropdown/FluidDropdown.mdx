In Afframe UI, `FluidDropdown` is used as Carbon ships it:

- With `invalid`, the button links `invalidText` through `aria-describedby`
  but gets no `aria-invalid`, so screen readers read the message without
  announcing the field as invalid. FluidDropdown passes extra props to its
  wrapper, not the button, so an app cannot add it (upstream issue drafted,
  not filed).

## Accessibility Considerations

### Accessible Name

The accessible name comes from `titleText`: Carbon renders it as the field's
`<label>`, so set it on every field. `label` is the placeholder text inside
the field and does not name it.
