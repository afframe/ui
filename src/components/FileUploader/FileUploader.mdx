## Overview

<Canvas of={FileUploaderStories.Default} />

FileUploader attaches files to a form. To import records from a file in a
dialog, use
[ImportModal](?path=/docs/components-task-dialogs-importmodal--overview),
which builds on `FileUploaderDropContainer` and `FileUploaderItem` and adds a
URL import.
