## Overview

The calendar is a full-page component that provides the users with a view of a selected month, week or day. The calendar can be used to display events in a summarized month view, or as a granular breakdown of days by hourly increments. The specified month, week or day that is displayed can be controlled through the mini calendar view or by using the arrows to jump to the previous or next date or date range. The user can also jump to the current date to see today’s information.

## Afframe notes

### Week start and region

The stories set `region="en-US"` as Labs does, so weeks start on Sunday.
Without `region`, the calendar follows the browser language. `region` also
sets the language of the month header and the mini calendar, so for Czech
users keep English names with a non-US English region and start weeks on
Monday:

```tsx
<Calendar region="en-GB" weekStartsOn={1} />
```

Two gaps remain in Labs 0.11.0, whatever the region (upstream issue drafted,
not filed): hour labels in the week and day views are always 12-hour (AM/PM),
and the mini calendar in the side panel ignores `weekStartsOn`, so with an
English region it starts weeks on Sunday.

<Canvas of={CalendarStories.WeekStartsMonday} />

### Narrow screens

The calendar is built for wide layouts. Below about 800 px, weekday names in
the month view are cut off, and at phone widths (375 px) the view switcher is
cut off too. Use it in a full-width page region, not in a side panel or a
phone layout (upstream issue drafted, not filed).
