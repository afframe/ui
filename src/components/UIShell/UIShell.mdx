## Which component to use

`@afframe/ui` ships two shells. This Carbon shell builds the header and side
nav from `Header` and `SideNav` parts. The Labs shell adds header popovers, an
overflow panel for small screens and a multi-level side nav. The Afframe header
parts fit either shell.
