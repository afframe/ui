## Accessibility

Labs 0.21.0 renders `Processing` with no role and no accessible name, and drops
every prop, so `aria-label` or `role` passed to it never reaches the DOM. Name
the busy state in a live region that is already mounted: a live region
announces changes, not its first render.

```jsx
<div role="status">
  {isGenerating && (
    <>
      <Processing />
      <span className="cds--visually-hidden">Generating answer</span>
    </>
  )}
</div>
```
