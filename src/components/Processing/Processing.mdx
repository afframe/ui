## Overview

Processing element is used to indicate that data is currently being
processed/loaded and the user should wait.

<Canvas of={ProcessingStories.LinearLoop} />

<img src={AIChatLoop} alt="AI chat window example" width={319} />

**Ex.** Content processing in a chat shell.
