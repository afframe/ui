# Security policy

How to report a vulnerability in `@afframe/ui`.

## Report a vulnerability

1. Open the Security tab of this repository on GitHub.
2. Select "Report a vulnerability".
3. Describe the problem, the affected files or exports and the steps to reproduce it.

- Do not open a public issue or pull request for a vulnerability.
- The maintainers reply in the private advisory.
- A vulnerability in Carbon itself goes to IBM: [carbon-design-system/carbon security policy](https://github.com/carbon-design-system/carbon/security/policy).
