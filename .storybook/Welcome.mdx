# Afframe UI

`@afframe/ui` is one React package built on IBM's Carbon Design System. It
carries Carbon, IBM Products, Carbon Labs, charts, the AI chat and Afframe's
own components, all imported from one path.

```tsx
import '@afframe/ui/styles.css';
import { AfframeProvider, Button } from '@afframe/ui';

export function App() {
  return (
    <AfframeProvider>
      <Button>Save</Button>
    </AfframeProvider>
  );
}
```

Set the theme on `<html>` with `data-afframe-theme` (see
[Theming](?path=/docs/getting-started-theming--overview)). Install,
registry access and the full setup:
[consuming guide](https://github.com/afframe/ui/blob/main/docs/guides/consuming.md).

to the name.
